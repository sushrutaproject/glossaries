# Glossaries

Searchable concordances of reference works on Indian materia medica, built from public scans.

| Work | Search | Data |
|---|---|---|
| Thakur Balwant Singh & K. C. Chunekar, *Glossary of Vegetable Drugs in Bṛhattrayī* (Varanasi, 1972) | [online search](https://sushrutaproject.github.io/glossaries/singh-chunekar-1972/) | [`singh-chunekar-1972/`](singh-chunekar-1972/) |
| Veṇīmādhavaśāstrī Jośī & Nārāyaṇa Harī Jośī, *Āyurvedīya Śabdakośa*, vol. 1 (Mumbaī, 1968) | [online search](https://sushrutaproject.github.io/glossaries/ayurvediya-sabdakosa-1968/) | [`ayurvediya-sabdakosa-1968/`](ayurvediya-sabdakosa-1968/) |

Each glossary folder has its own README describing what the data contains, how it was made and how reliable it is.

(headwords, gender, page numbers, botanical names, citations), and the search pages show the original page images live from
the Internet Archive via IIIF.
